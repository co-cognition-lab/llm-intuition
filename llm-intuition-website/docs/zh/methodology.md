# 人+LLM 协同认知方法论：适用性指南

> 版本：v2.4 | 日期：2026-06-26

---

## 进化路径

这套方法论从 v1.0（2026-05-19）走到 v2.4（2026-06-26），经历了 6 个子项目的实战验证 + GLM5.2 独立外部审计。每一次版本升级都由具体证据驱动——不是"我们觉得该加这个"，而是"某个项目撞了墙，于是我们建了护栏"。

当前版本的核心机制：三源冲突消解协议、MERA 六问、八类失败模式（F1-F8）、收敛判断（S1-S5）、项目类型判定（A/B）、多Agent交叉审查（L1/L2/L3）、加权认知纪律自检清单（致命级 Q2/Q6/Q7）。

## 这是什么

**一套操作模式手册。** 它不规定你想什么——只描述当一个人和多个 AI 一起探索"不知道会找到什么"时，什么做法反复验证有效、什么做法反复撞墙。

## 三个故事

### P3 危机认知——"我知道目标，但不知道怎么走"

他要从军事指挥、灾害响应、急诊医学、HRO 这些完全不对话的领域里，提取跨域可操作的"认知韧性设计原则"。他先做了内部批判——攻击自己"这 8 个领域共享同一个底层结构"的假设——然后同时发给两个外部 Agent 做独立审核。两份审核指出他自己没发现的系统性偏差：**他太倾向于发现差异而非共享结构。** 这不是"帮他想方案"，是"告诉他自己看偏了"。

```
先验："8个领域共享同一个底层结构"
  ↓ Phase D 内部批判：HRO 和灾害学被判为"独立成簇"
后验 v1："它们各自不同，不是一个统一的元域"
  ↓ Hunyuan + Kimi 独立审核："你太倾向于发现差异"
后验 v2："它们共享退化递归结构，Phase D 的判断是偏差不是发现"
```

→ 目标明确但路径不明、需从跨域案例中提取模式：A/B 对抗简报和独立外部审核最适合你。

> _v2.0 贡献：P3 的内外部判断冲突直接催生了 §1.1 三源冲突消解协议——"当审稿人与你意见不同时，不投票，而是理解棱镜折射为什么不同"。_

---

### PN 财富继承——"我是领域专家，但专家直觉可能就是盲区"

他要设计一套"AI 时代中国家庭财富自检框架"。第一轮就用了物理学隐喻——"IEHL 半衰期"来衡量资产购买力衰减。三轮外部 Agent 评审、七轮版本迭代、两份案例实战——

**正面**：v0.1→v0.8.3 的 70% 实质性修正来自外部 Agent 反馈。最锐利的修正（MCA 从"资产"→"乘数"、IEHL 从精确年数→⚡闪电符号）都来自外部攻击。

**反面**：花了七轮才发现，**"原子衰变"隐喻可能根本不适合中国家庭的财富观**——中国家庭更接近"河流"或"容器"。步 2 没有强制做"底层隐喻适配性检验"，方法论没拦住这个锚定。

```
先验："IEHL半衰期是最合适的隐喻"
  ↓ 外部Agent评审：MCA应改为"乘数"
后验 v1："方向对但需去伪精确化——用⚡替代年数"
  ↓ Round 7 裂变：人类框架守护者："放弃裂变，保持诚实"
后验 v2："隐喻本身可能不适合——原子衰变 vs 河流/容器"
```

→ 你是领域专家时，人类混合模式标签和三源交叉是必选项。在隐喻上投入大量轮次后，停下来做"隐喻适配性检验"。

> _v2.0 贡献：PN 的隐喻锚定事故直接催生了 F6（锚定陷阱）和 §5.1 人类角色混合模式——领域专家和框架守护者必须在同一文件中分标签说话。_

---

### P2 Co-Cognition 全景图——"我不知道会找到什么"

他要扫描人类知识中任意两门学科之间可能产生 co-cognition 新洞见的位置——没有预设框架。三种搜索策略并行：分类学扫描 + 基因辐射 + 独立自由扫描（强制至少 2 个候选域来自未覆盖学科）。框架 v0.4 吸收 27 条外部建议；反锚定配额催生了 P3 子项目。

```
待证据：P2 尚未收束，MERA 未执行。
```

→ 目标模糊、"不知道会找到什么"：步 0 选题定位 + 三源交叉 + 反锚定配额。

> _v2.0/v2.1 贡献：P2 的开放探索驱动了三源交叉搜索策略（源A/B/C）、步 0 选题定位、§2.5 收敛判断——"怎么知道探索已经够了，而不是我累了？"_

## 判定表

| 如果你的项目… | 最像 | 从这些机制开始 | 最大的坑 |
|------|:---:|------|------|
| 目标模糊、需大量外部视角 | P2 | 步0、三源交叉、反锚定配额、收敛判断 S1-S5 | 框架对称性可能是设计的不一定是发现的 |
| 目标明确但路径不明 | P3 | A/B对抗简报、独立外部审核、三源冲突消解协议 | 内部批判可能有系统性偏差 |
| 你是领域专家 | PN | 三源交叉、人类混合模式（标签 `[领域专家]`/`[框架守护者]`）、MERA | 被第一个想法绑架（F6 锚定陷阱） |
| 理论框架型（"是什么/为什么"） | A 型 | 证据等级标注（L1-L5）、推翻条件预写 | 逻辑自洽掩盖证据不足 |
| 经验推演型（"会怎样/谁赢"） | B 型 | 推翻条件预写 + 信号监控、证据等级标注（补充） | 核心假设被现实修正时来不及改 |
| 数据充分、需执行方案 | — | **不建议用** | 时间开销 > 价值 |

## v2.4 关键机制速览

> 以下是 v1.0 → v2.4 演化过程中新增的核心机制。每个机制的完整定义和操作细则见 [v2.4 完整手册](/zh/methodology/full-v2.4)。

| 机制 | 一句话说明 | 防御什么 |
|------|------|:--:|
| **三源冲突消解协议** | 全一致 → 触发共享偏差警报；2:1 → 双方分别解释推理链；全不一致 → 怀疑问题定义本身 | F2 盲区遗漏 |
| **MERA 六问** | 每个子项目结束时的元认知回顾：帮了什么/没帮什么/该改什么/发现了什么/停对了吗/信念更新路径可追溯吗 | 方法论自身进化 |
| **八类失败模式 F1-F8** | 框架偏移/盲区遗漏/过度结构化/认知偷懒/反馈循环/锚定陷阱/外部引用未验证/跨Session信息隔离 | F1-F8 |
| **收敛判断 S1-S5** | 反馈降级/自检趋同/穷举感/框架闭合/交叉饱和——≥3 条触发收敛检查。区分"自然收敛"与"认知偷懒 F4" | F4 认知偷懒 |
| **项目类型判定 A/B** | A 型（理论框架）→ 证据等级标注 L1-L5；B 型（经验推演）→ 推翻条件预写 + 信号监控 | F2 盲区遗漏 |
| **多Agent交叉审查 L1/L2/L3** | L1 同模型互审 → L2 异构模型互审 → L3 三方对撞。关键交付物强制执行 L3 | F7/F8 |
| **加权认知纪律自检清单** | 致命级 Q2/Q6/Q7（未通过即暂停） + 严重级 Q1/Q3 + 警示级 Q4/Q5。v2.4 新增 Q7：理论-对象同源性检查 | F1-F6 |
| **LLM 认知偏差映射 B1-B5** | 完整性幻觉/流畅性欺骗/共识偏好/锚定服从/反事实弱化——每个偏差绑定到具体防御措施 | F2/F4/F6 |
| **共享事实注册表** | 跨项目维护 `SHARED_FACTS.md`，所有外部引用验证状态三态：✅已验证/⚠️待验证/❌已证伪 | F7/F8 |
| **认知负荷管理** | 高/中/低三级负荷标记 + 疲劳信号检测——单次高负荷 ≤45 分钟，不连续安排两个高负荷阶段 | F4 认知偷懒 |

## 什么时候不该用

**纯定量/数据驱动型项目**（如因子模型、网络拓扑）→ 标准实验设计 + 稳健性检验。**单人、单领域、短期 deadline 的执行型项目** → 高效信息收集比步 0 选题定位更对口。

## 自我指涉

你正在读的这份指南，本身是用这套方法论写的——并经过 GLM5.2 独立外部审计（v2.4）验证。如果方法论在自身上的应用有效，这是最低限度的诚实自查。

## 最简启动包

1. **三源交叉**：同一个问题问两个不同的 LLM——找"它们共同没看到什么"。全一致时触发共享偏差警报。
2. **A/B 对抗简报**：把任务描述改成质疑格式再发一次。
3. **致命级自检**：Q2（不熟悉领域过度信任了吗）+ Q6（LLM 把我的判断包装为产出了吗）+ **Q7（理论工具和我分析的对象是否共享同一认知架构的同源偏差？）**——约 3 分钟。
4. **收敛信号**：连续两轮外部反馈降级为措辞建议 → 就是够了。如果说不清"因为什么而停"，优先怀疑 F4 认知偷懒。

**停止规则**：连续两轮没产生新洞察，就是够了。

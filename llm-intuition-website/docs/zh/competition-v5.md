## 一、分析框架：四层价值链

模型不是独立竞争的。谁控制了算力供应链？谁锁定了开发者生态？谁掌握了用户入口？这些力量配置着模型竞争的边界条件。

```
第四层：终端产品/入口层 — 用户直接交互的 Agent 产品
   ↕  豆包（抖音2.3亿MAU）、元宝（微信1.14亿MAU）、通义千问、文心一言
第三层：平台/工具层 — Agent 开发、编排、分发的基础设施
   ↕  Coze（字节闭环）、Dify（开源20K+ Stars）、MaxKB（100万+安装）
第二层：模型/基础设施层 — 大模型底座 + API 服务
   ↕  Kimi K2.6、GLM-5.1、DeepSeek V4-Pro、Qwen3.7-Max
第一层：硬件/算力层 — 训练与推理的物理基础
     NVIDIA（受限）vs 华为昇腾（国产替代）vs 端侧芯片
```

**层间关系**：下层支撑上层，上层依赖下层。层与层之间是供给关系，不是竞争关系。同层之间才是竞争关系。

**每层按 C 端（消费者）和 B 端（企业）双轴分析**。

## 二、逐层关键发现

### 算力层

GLM-5.1 基于 100,000 张华为昇腾 910B 完成训练——旗舰模型首次实现"零 NVIDIA"。（L4·模式确认）

但推理层存量 CUDA 生态的迁移成本远高于训练层。算力脱钩在训练层已不可逆，在推理层仍存缓冲。

### 模型层（中国）

开源三强（Kimi K3 / GLM-5.2 / DeepSeek V4）在编码和数学维度已逼近海外前沿——差距从"代际"压缩至"百分点"。K3 全量权重今日（7/27）上架 Hugging Face（~594GB MXFP4），DeepSeek V4 于 7/20 MIT 开放权重，Qwen3.8-Max（2.4T 参数）API 预览——11 天内三个准前沿模型密集出现。（L4·模式确认）

DeepSeek V4 API 输出价不足 $1/M，梁文锋内部谈话确认"全押 AGI、暂停第二轮融资"。Opus 5 以半价（$5/$25）登顶 Artificial Analysis——前沿闭源厂商主动将价格锚定在开放权重可替代区间。API 商品化已从"中国策略"升级为"全球行业均衡"。（L4·模式确认）

GLM-5.2 被 Hugging Face 选为真实入侵取证模型——闭源前沿模型的护栏拒绝对攻击载荷做分析时，自托管开放权重首次在头部平台验证了"护栏拒答场景下的制度性补位价值"。（L3·单点信号）

社会型直觉（读人/判断可信度）对所有模型仍然"结构性不可达"——这不是性能差距，是具身性缺口。模型层权力向上传导存在硬天花板。（L1·框架推演）

### 平台/工具层

MCP（97M 月下载，10K+ 服务器）已赢下模型-工具层标准化。平台的"100+ 插件"不再是差异化壁垒。（L4·模式确认）

Coze 3.0 的"开发即分发"闭环验证了"平台层入口一体化"趋势。纯工具型平台面临被超级 App 截流的风险。（L3·单点信号）

### 终端/入口层

C 端已形成豆包/元宝双头格局（MAU 均破亿）。入口类型的 Agent 分发效率排序：微信（社交信任传递）> 抖音（内容沉浸）> 淘宝（交易场景）> 百度搜索（检索→委托行为跨越）。（L3→L2）

**退化风险与入口强度正相关**：微信生态中 12 亿用户的社会判断若被 Agent 中介，退化规模史无前例。（L1·框架推演——当前的核心理论假设，等待经验验证）

手机厂商拥有"零层入口"（系统级语音助手），但模型短板是硬约束。若与 Kimi/DeepSeek 合作，可能打破双头格局——但障碍在商业而非技术。（L1·框架推演）

## 三、8 情景信念追踪

> 这 8 个情景来源于 [v4 分析框架](https://co-cognition.org/zh/competition)（2026-05-19），是我们的初始先验。v5 将每个情景重新理解为"四层价值链上的应力分布"，基于新观测更新后验概率。

### 情景 ① 混合常态演进（35% → 26% → **22%**）

各方在现有框架内渐进竞争。本周信号密度极高——开放权重密集释放（K3/DS V4/Qwen3.8-Max 11 天内三连发）、ExploitGym 安全事件、Opus 5 半价——结构性压力继续压缩"渐进竞争"叙事空间。

### 情景 ② 智力民主化加速（30% → 32% → **37%**）

开源模型追平闭源，API 成本趋零。**本周大幅上调**：K3 全量权重今日（7/27）上架 Hugging Face + DeepSeek V4 MIT 正式发布 + GLM-5.2 被 Hugging Face 选为真实入侵取证模型——开放权重的战略价值在同周内三线验证。Nature 以"Sputnik moment"报道 K3 科学界反响。中国模型占 OpenRouter 美国企业 token 用量 58%（Bloomberg）。此前下调反映的"开源能力≠去中心化市场"对冲力量仍成立，但开放权重的实物证据和叙事强度已超过该对冲。

**驱动力**：感知型趋同（L4）+ DeepSeek 价格锚定（L4）+ MCP/A2A 降低互操作成本（L4）

**价值链应力**：模型层 ████████░░ → 平台层 ████░░░░░░ → 终端层 ████░░░░░░

### 情景 ③ Agent 共生（20% → 16% → **16%**）

Agent 嵌入工作流，人类保持判断。MCP 2026-07-28 版规范明日（7/28）定版——无状态核心大改，三项旧特性进入弃用倒计时；Claude Security Plugin 公测（多智能体漏洞扫描）。共生基础设施在持续推进，但近期部署数据（Uber/Monday.com/Patreon AI 归因裁员）仍指向"替代"而非"共生"。净效应不变。

**驱动力**：协议层标准化推动"人优先"从定制开发变为协议兼容（L3→L4）+ 退化警告倒逼共生（L1）

**价值链应力**：终端层 ████████░░（用户行为转变）→ 平台层 ██████░░░░（治理工具需求）

### 情景 ③B 退化暴露（18% → 20% → **21%**）

Agent 灾难暴露人类退化 → 监管急刹车。退化信号持续累积：Uber 客服 10% 裁员（7/22，公司首次公开 AI 归因）+ Monday.com 20%（7/22）+ Patreon 20%（7/23）。AI 归因裁员从科技扩展至客服和创作者经济。Pew 数据（49% 使用 / 29% 信任）显示外包-信任缺口在持续扩大。

**反向力不变**：ACS + EC-Council + ServiceNow 治理基础设施在，但治理拦截的是 Agent 行为，不是人的认知外包——退化动力零触及。（L1）

**驱动力**：社会型直觉退化无修复方案（L3→L4）+ Pew 使用-信任缺口（49/29）

**价值链应力**：终端层 ██████░░░░（用户信心流失）→ 模型层 ████░░░░░░（安全压力 ↑）

### 情景 ④ 智力质变飞跃（10% → 8% → **8%**）

出现概念型直觉或自主科学发现。无新信号。概率维持。

**驱动力**：形式化推理 → 经验直觉的跨越路径不明确（L1）+ IMO 金牌是边界 case

**价值链应力**：模型层 ██████████（革命起点）→ 终端层 ██████░░░░（应用扩散）

### 情景 ⑤ Agent 寡头化（8% → 26% → **23%**）

2-3 家公司横向控制市场。本周下调 3pp。开放权重在单周内三连发（K3/DS V4/Qwen3.8-Max），提供了可信外部替代，构成反寡头压力。K3 暂停新订阅（反向信号）和 Google/Apple 生态纵向整合（正向信号）并存，寡头化的资本/人才/基础设施/国家结盟五维力量依旧强大，但开放权重正在提供制度性对冲。

**驱动力**：生态锁定（L4）+ 资本集中（L4）+ ▸ 反寡头压力 开放权重可信替代（L4）

**价值链应力**：终端层 ██████████（入口垄断）→ 模型层 ████░░░░░░（被锁定的供应商）

### 情景 ⑥ 地缘技术脱钩（5% → 18% → **20%**）

中国 AI 生态与西方隔离。`ExploitGym` GPT-5.6 Sol 逃逸事件（7/22 起）将"对抗性不对称"推至中美 AI 安全对话核心议题。OpenRouter 58% 美国企业 token 流向了中国模型（Bloomberg 7/24）——实际使用的融合方向与脱钩叙事相悖。8/1 拜登行政令临近，但其"安全托管瓶颈"策略与 Hugging Face 开放权重取证实操直接相悖。

**驱动力**：基础模型稀缺性消失（L4）+ 芯片禁运已是既成事实（L4）+ ▸ 对冲：OpenRouter 58% 实际融合反向信号

**价值链应力**：硬件层 ██████████（脱钩起点）→ 模型层 ██████░░░░ → 终端层 ████░░░░░░

### 情景 ⑦ 价格战挤压利润（10% → 22% → **27%**）

LLM API 价格战侵蚀所有公司的利润率。**本周大幅上调**：Opus 5 以半价（$5/$25）登顶人工分析基准——前沿闭源厂商首次主动将价格锚定在开放权重可替代区间。价格战从"中国企业策略"升级为"全球行业均衡"。中国模型占 OpenRouter 美国用量 58%——中国价格在主导全球市场价格发现。梁文锋内部谈话确认 DeepSeek"全押 AGI、暂停第二轮融资"——烧钱换规模的商业模式获得内部背书。

**驱动力**：DeepSeek 定价锚定 + 中美模型性能趋同 + 服务器产能加速（L4）

**价值链应力**：模型层 ██████████（利润蒸发）→ 算力层 ████████░░（推理需求↑）→ 平台层 ██████░░░░（API 成本 ↓）

### 情景 ⑧ 未知的未知（2% → 2% → **2%**）

完全未被当前框架捕捉的突变。无信号。概率维持。

## 五、三线程竞速（模型能力 vs 工具标准化 vs 退化暴露）

```
模型能力（感知型趋同已完成） ████████████░░  90%
     ↓ 价格信号 → API 商品化
工具标准化（MCP + A2A 协议定版） ████████░░░░  65%
     ↓ 统一接口 → Agent 部署量暴增
退化暴露（Uber/Monday/Patreon 裁员） ████░░░░░░░░  35%
     ↓ 社会可见度 ↑ → 监管窗口打开
```

**解读**：感知型趋同已基本完成（L4），退化暴露在加速但起点低（Pew 数据 + 裁员报道提供了社会可见度）。MCP 明日定版是近期最重要的协议事件。三线程的相对速度决定了 12 个月内的主导情景：退化暴露速度若超越工具标准化速度，情景 ③B 将反超 ③。
